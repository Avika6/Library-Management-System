# 📚 Library Management System

A Python-based Library Management System developed as a **group project** to simplify and organize basic library operations.

## 📌 About the Project

The Library Management System is designed to manage library activities through a menu-driven Python application. It helps organize book records, member information, fines, and library statistics.

The project uses CSV files for storing and managing data.

## ✨ Features

- **Book Management:** Manage book records and information.
- **Member Management:** Maintain library member details.
- **Fine Management:** Manage library fines.
- **Book Recommendations:** Provide book recommendations.
- **Library Statistics:** Generate library-related statistics and reports.
- **CSV Data Storage:** Store and manage records using CSV files.

## 🛠️ Technologies Used

- Python
- CSV module
- OS module
